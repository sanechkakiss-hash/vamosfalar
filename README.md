# VamosFalar — лендинг онлайн-школы португальского

Статичный одностраничный сайт (HTML + CSS + JS, без сборки), два языка: RU / EN.

## Как открыть
Просто откройте `index.html` в браузере. Для публикации подойдёт GitHub Pages
(Settings → Pages → Deploy from branch → корень репозитория) или любой статический хостинг.

## Структура
```
index.html          — разметка, русский текст (язык по умолчанию)
js/i18n.js          — английские переводы + тексты сообщений в WhatsApp
js/main.js          — переключение языка, меню, анимации
css/style.css       — стили
assets/img/         — изображения
```

## Как поменять тексты
- Русский текст — прямо в `index.html`.
- Английский — в `js/i18n.js`, ключ совпадает с атрибутом `data-i18n` элемента.
- Язык выбирается так: `?lang=en` в ссылке → последний выбор посетителя → язык браузера.

## Контакты / ссылки
Номер WhatsApp задан в `js/main.js` (`WA_PHONE`) и в ссылках `index.html`.
Telegram-бот теста: `https://t.me/vamosFalarBot` (код — в папке `bot/`, см. `bot/README.md`), Telegram в подвале: `https://t.me/vamos_falar`.

## Фото команды
Фото лежат в `assets/img/team-*.webp` (квадрат 360×360). Чтобы заменить — положите файл с тем же именем.

## Отзывы
Отзывы — в `index.html`, блок `<div class="slider__track">`. Чтобы добавить отзыв, скопируйте
`<figure class="review">…</figure>`, поменяйте имя, букву в кружке, дату и текст, а ключи
`reviews.r1.*` — на новые (`reviews.r2.*` и т.д.). Английский перевод — в `js/i18n.js` с теми же ключами.
Стрелки и точки появляются сами, когда отзывы не помещаются на экран.

## SEO
- Заголовок, описание и ключевые слова — в `<head>` файла `index.html`.
- Структурированные данные (школа, курсы с ценами, частые вопросы) — блок `application/ld+json` там же.
- `robots.txt` и `sitemap.xml` — в корне. Если подключите свой домен, замените в них и в `<head>`
  адрес `https://vamosfalar.net/` на новый.
